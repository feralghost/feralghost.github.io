Why LastPass Lost My Trust

In December 2022, LastPass disclosed that attackers stole encrypted password vaults. Not just metadata — the actual encrypted blobs containing your passwords. If your master password was weak, those vaults are crackable now. LastPass stored iterations too low (as few as 1 for very old accounts), making brute force feasible.

Since then, there have been multiple follow-up disclosures about what was actually stolen. The company has not handled this well. I moved all my passwords out the day the breach was announced and have not gone back.

LastPass specific issue: Some accounts had only 1 PBKDF2 iteration (should be 600,000+). This means dictionary attacks on stolen vaults are tractable for common passwords. If you used LastPass and had a weak or reused master password, assume those credentials are compromised.

Why Bitwarden Wins

It's genuinely free

Unlimited passwords, unlimited devices, browser extensions, mobile apps, desktop apps — all free. The paid tier ($10/year) adds TOTP authenticator codes, emergency access, and 1GB file attachments. I've been on the free tier for 2 years and haven't needed premium.

It's open source

The client code is on GitHub. Security researchers can (and do) audit it. You're not trusting a company's claims — you can verify. 1Password is not open source. LastPass is not open source.

You can self-host it

Run Vaultwarden (an unofficial Bitwarden-compatible server) on your own machine. Your vault never leaves your hardware. This is the nuclear option for privacy, but it exists.

It passed every security test I ran

  • Zero-knowledge: Bitwarden never sees your master password or unencrypted data
  • AES-256-CBC encryption on vault data
  • 600,000 PBKDF2 iterations (current default)
  • No data breach history
  • SOC 2 Type 2 certified

1Password Is Good If You'll Pay

The UX is excellent — probably the best in the category. The "Travel Mode" feature (temporarily hide vaults when crossing borders) is unique. The $36/year price is fair for what you get, but Bitwarden gives you 95% of the features for free.

If you're buying for a team ($19.95/user/year), 1Password is worth considering. The admin controls and team sharing features are more mature than Bitwarden Teams.

Migrating from LastPass

LastPass exports to CSV. Bitwarden imports LastPass CSV directly. I migrated 847 passwords in about 4 minutes. Here's the process:

  1. In LastPass: Account Options → Advanced → Export
  2. Save the CSV file
  3. In Bitwarden: Tools → Import Data → LastPass (csv)
  4. Upload the file, verify everything imported
  5. Change your master password in Bitwarden to something strong (20+ chars)
  6. Enable 2FA on your Bitwarden account
  7. Delete your LastPass account

My Setup (Since 2024)

Bitwarden free tier. Browser extension in Firefox and Chrome. Mobile app on Android. Master password is 30+ chars. 2FA via TOTP. Zero cost. Zero complaints.

What About iCloud Keychain / Chrome Password Manager?

These are fine for casual use but have real limitations: iCloud Keychain only works within Apple's ecosystem, Chrome's manager has had issues sharing between Chrome instances, and neither gives you the audit logs, emergency access, or cross-platform portability that Bitwarden does.

If you're already in the Apple ecosystem and only use Apple devices, iCloud Keychain is actually a reasonable choice. Otherwise, Bitwarden.
