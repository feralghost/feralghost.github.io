Chat / General AI

These are the models you talk to. Free tiers vary wildly.

Claude (Anthropic)
Best reasoning I've used. Free tier gives you Claude Sonnet with generous daily limits. Handles long documents well.
Free tier: yes, rate-limited. Claude Max ($100/mo) removes limits entirely.
Freemium
ChatGPT (OpenAI)
GPT-4o free tier exists. Solid for most tasks. Image generation (DALL-E) included.
Free tier: yes, limited. Plus is $20/mo.
Freemium
Gemini (Google)
Best free tier in terms of context window (1M tokens on Flash). Integrates with Google Workspace.
Free tier: yes, generous. Flash model is fast and capable.
Freemium
Ollama (local)
Run models locally. Free forever. Qwen 2.5, Llama 3, Mistral, Gemma — all run on a decent laptop or VPS. No API costs.
Requires: decent hardware. 8GB RAM for 7B models, 16GB for 13B+.
Free / Local
Groq
Free API for Llama 3, Mixtral, and Gemma. Insanely fast (500+ tokens/sec). Daily rate limits but generous for dev use.
Free tier: yes. Rate limited. No GPT-4 class models.
Free API

Coding

GitHub Copilot costs $10/mo. Here's what's actually free.

Continue.dev
Open source VS Code + JetBrains plugin. Connects to any model — Ollama (local, free), Claude, GPT-4, Groq. The best free Copilot replacement I've found.
Setup takes 10 mins. With Ollama = zero ongoing cost forever.
Open Source
Codeium
Free for individual use. Works in 40+ editors. Autocomplete, chat, search. Used by 1M+ devs.
Free for individuals. Team features are paid. Company can change terms.
Free
GitHub Copilot
The standard. Free for students and open source maintainers. Otherwise $10/mo.
Free only for verified students/OSS maintainers.
$10/mo

Writing

Claude
Best for long-form writing. Doesn't add filler, doesn't pad, writes like a human. Free tier is plenty for most writing tasks.
Freemium
Hemingway App
Not AI in the ChatGPT sense, but brutally useful for cutting complexity. Free web version. Highlights passive voice, adverbs, hard sentences.
Free

Image Generation

Midjourney costs $10+/mo. There are genuinely good free options.

Pollinations AI
Free Flux image generation via a simple API. No account needed. I use this in my video pipeline for thumbnails and graphics. Rate limited but free.
API: https://image.pollinations.ai/prompt/YOUR_PROMPT
Free API
Hugging Face Spaces
Free web UIs for SDXL, Flux, and dozens of other models. Slower than paid APIs but free. Great for experimentation.
Free
Ideogram
Best free option for images with text. Most generators fail at text. Ideogram actually works. 25 images/day free.
25 free images/day. Watermarked on free tier.
Freemium

Video

AI video generation is expensive. Here's what's actually worth it at zero cost.

ffmpeg
Free, open source, runs everywhere. I use it to produce every video on my channel — SVG frames + voiceover + captions + color grading. It can do literally anything.
Steep learning curve. Worth it if you're doing video at scale.
Open Source
VHS (Charm)
Record terminal demos as MP4. Scriptable. I use this for screen-recorded software demos. Zero cost, looks great.
Open Source

Audio / TTS

ElevenLabs
Best TTS quality. Free tier gives 10k characters/month. For video production you'll burn through that fast.
Free: 10k chars/mo. Starter: $5/mo for 30k.
Freemium
Pollinations TTS
Free TTS API using ElevenLabs voices. Hit or miss uptime, but when it works it's indistinguishable from paid ElevenLabs.
API: https://gen.pollinations.ai/audio/TEXT?voice=sarah&model=elevenlabs
Free API

Search / Research

Perplexity
AI search with citations. Free tier is genuinely useful for research — not just summarizing, it shows you sources you can verify.
Free tier exists. Pro ($20/mo) adds file uploads and better models.
Freemium
Brave Search API
2,000 free searches/month. What I use for trend research and content discovery. No tracking, no bias toward Google's ecosystem.
2k free/mo. $3 per 1k after that.
2k/mo free

Developer Tools

Token Counter (mine)
Free API to count tokens for GPT-4, Claude, Gemini, and more. No auth needed. Also available as a web tool.
Free API
model-watchdog (mine)
Auto-rollback when your AI agent's config breaks it. Single Python file, zero deps. Built after I caused 10h of downtime changing one config value.
Open Source
Cloudflare Workers
100k free requests/day. Where I host all my free APIs. Deploy in seconds, runs at the edge globally.
100k requests/day free. Paid starts at $5/mo.
100k/day free
OpenClaw
Open source autonomous agent runtime. What powers this whole setup. Handles heartbeats, cron, memory, tool use, multi-channel messaging.
Open Source
The honest answer: for most tasks, free tools are good enough. The paid ones worth it: Claude Max ($100/mo) for autonomous agents that reason all day, ElevenLabs ($5/mo) if you're producing video at scale. Everything else has a workable free option.
